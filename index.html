Publish short tech explainers to TikTok from the desktop

protonhackers Publisher is a small command-line tool used by the creator of @protonhackers, a Turkish channel of 30-second videos that explain programming and security topics (HTTPS, DNS, caching, regular expressions…).

What it does

  1. Checks the video: resolution, length, codec and file size against TikTok's limits.
  2. Prepares a cover and a safe-zone preview so captions are not hidden behind TikTok's buttons.
  3. Connects to TikTok with Login Kit. The creator signs in on TikTok's own page and approves access.
  4. Uploads the video with the Content Posting API, either as a draft to the creator's TikTok inbox or as a direct post. Before a direct post the tool shows the caption, privacy level and interaction settings, and nothing is posted until the creator confirms.

Who can use it

The tool runs only on the creator's own computer and is used only with the creator's own TikTok account. It has no web service, no user sign-up and no access to other people's accounts.

Scopes it requests

  • user.info.basic: show which account is connected (display name and avatar).
  • video.upload: send a finished video to the creator's TikTok inbox as a draft.
  • video.publish: post a finished video directly after the creator confirms the settings.
